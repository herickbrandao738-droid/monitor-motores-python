// O QUE ESTE CÓDIGO FAZ?

O script em Python simula um Sistema de Telemetria e Manutenção Preditiva Industrial. Ele recebe leituras brutas de sensores instalados em quatro motores elétricos de uma fábrica, filtra dados corrompidos ou negativos, compara os parâmetros físicos contra limites de segurança, calcula médias gerais da planta e gera um plano automatizado de ação para a equipe de engenharia.

PIPELINE DE PROCESSAMENTO DE DADOS

I

Ingestão & Constantes

Define os limiares físicos (Temperatura, Corrente, Vibração e RPM) e armazena os dicionários com as leituras dos 4 motores.

➔
II

Sanitização

A função validar_leitura() verifica se existem campos nulos, ausentes ou valores fisicamente impossíveis (negativos).

➔
III

Motor de Regras

analisar_alertas() cruza os sensores com os limites e classifica cada máquina em NORMAL, ATENCAO ou CRITICO.

➔
IV

Relatório & Ação

Consolida estatísticas globais, imprime o painel em tempo real e segrega os motores em filas de manutenção preventiva.

⚠️ CURIOSIDADE TÉCNICA NO SEU CÓDIGO

Observe o final do seu script: existem dois blocos if __name__ == "__main__":. Quando o Python executa o arquivo, ele roda o primeiro bloco (exibindo o painel uma vez) e logo em seguida executa o segundo bloco (exibindo o painel novamente e depois o plano de manutenção). Na aba 04. Saída do Terminal, você verá exatamente esse comportamento duplicado!

MÓDULO 02 // SEGURANÇA

Validação e Filtragem de Sensores

def validar_leitura(motor):
    campos_obrigatorios = ["id", "setor", "temperatura", ...]
    for campo in campos_obrigatorios:
        if campo not in motor or motor[campo] is None:
            return False
    if motor["temperatura"] < 0 or motor["corrente"] < 0 ...:
        return False
    return True

def obter_leituras_validas(lista_motores):
    return [m for m in lista_motores if validar_leitura(m)]

O que acontece aqui:

  • Garante integridade antes de qualquer cálculo matemático, evitando erros como KeyError ou TypeError.
  • Bloqueia sensores defeituosos que enviem valores negativos.
  • obter_leituras_validas() utiliza List Comprehension (uma estrutura elegante do Python) para filtrar apenas os motores aprovados. No seu exemplo, todos os 4 passam.

def analisar_alertas(motor):
    alertas = []
    if motor["temperatura"] > LIMITES["temperatura_max"]: ...
    if motor["corrente"] > LIMITES["corrente_max"]: ...
    if motor["vibracao"] > LIMITES["vibracao_max"]: ...
    if motor["rpm"] < LIMITES["rpm_min"] or ...: ...

    if len(alertas) == 0: status = "NORMAL"
    elif len(alertas) == 1: status = "ATENCAO"
    else: status = "CRITICO"
    return status, alertas

O que acontece aqui:

  • Cada métrica é testada de forma independente (quatro blocos if separados, não elif), permitindo acumular múltiplos defeitos simultâneos.
  • Regra de Severidade: 0 falhas = NORMAL; 1 falha = ATENCAO; 2 ou mais falhas = CRITICO.
  • Retorna uma tupla contendo a string de status e a lista descritiva das anomalias.
